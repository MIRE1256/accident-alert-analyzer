# 🚨 ระบบวิเคราะห์โพสต์เตือนภัยและข่าวอุบัติเหตุ (Accident Alert Analyzer)

ระบบเว็บแอปพลิเคชันสำหรับประมวลผลภาษาธรรมชาติ (NLP) ภาษาไทย เพื่อสกัดข้อมูลสำคัญจากข้อความแจ้งเตือนภัย สเตตัสโซเชียลมีเดีย หรือโพสต์ข่าวอุบัติเหตุแบบอัตโนมัติ ช่วยให้เจ้าหน้าที่และประชาชนสรุปประเด็นเหตุการณ์ได้อย่างรวดเร็ว

---

## 💡 แนวคิดของ Domain (Domain Concept & Rationale)

ในสถานการณ์ฉุกเฉิน อุบัติเหตุ หรือภัยพิบัติ ข้อมูลข่าวสารบนโซเชียลมีเดียจะเกิดขึ้นอย่างรวดเร็วและกระจัดกระจาย ข้อความส่วนใหญ่มักเป็นภาษาพูดที่ไม่เป็นทางการ มีคำแสลง เว้นวรรคไม่เป็นระบบ หรือมีข้อความรบกวน (Noise) เช่น เบอร์โทรศัพท์ หรือลิงก์เว็บ

**วัตถุประสงค์ของระบบ:**
1. **ลดเวลาอ่านข้อความ (Information Extraction):** ดึงเฉพาะสาระสำคัญ 4 ด้านหลัก ได้แก่ **สถานที่เกิดเหตุ, วันเวลา, ผู้บาดเจ็บ/เสียชีวิต, และหน่วยงานเข้าช่วยเหลือ**
2. **จำแนกประเภทเหตุการณ์ (Topic Classification):** ระบุหมวดหมู่ภัยพิบัติอัตโนมัติ (เช่น อุบัติเหตุจราจร, เพลิงไหม้, น้ำท่วม, ภัยสารเคมี)
3. **สนับสนุนการตัดสินใจ:** ปรับโครงสร้างข้อมูลแบบ Unstructured Text ให้เป็น Structured Data เพื่อนำไปวิเคราะห์ต่อหรือส่งต่อหน่วยงานกู้ภัยได้อย่างทันท่วงที

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **Language:** Python 3.9+
* **Framework:** Streamlit (UI & Web Deployment)
* **NLP Library:** PyThaiNLP (Thai Text Tokenization & Processing)
* **Text Processing:** Regular Expressions (Regex), Pandas

---

## 🤖 ตัวอย่าง Prompt ที่ใช้สั่ง AI ในการพัฒนาโปรเจกต์ (AI Prompts Used)

ในกระบวนการพัฒนาโปรเจกต์นี้ ได้มีการใช้ AI เป็นคู่คิดและสร้างโค้ดส่วนต่างๆ โดยใช้ Prompt ดังต่อไปนี้:

### 1. Prompt สำหรับการออกแบบโครงสร้างการสกัดข้อมูล (NLP & Regex Engine)
> *"ช่วยเขียนฟังก์ชัน Python สำหรับทำ Information Extraction จากข้อความข่าวอุบัติเหตุภาษาไทย โดยใช้ PyThaiNLP และ Regular Expression (Regex) เพื่อดึงข้อมูล 4 ส่วน ได้แก่: 1. สถานที่เกิดเหตุ 2. เวลาเกิดเหตุ 3. จำนวนผู้บาดเจ็บ/เสียชีวิต 4. หน่วยงานช่วยเหลือหรือกู้ภัย พร้อมทำ Text Cleansing ลบ URL และเบอร์โทรศัพท์ออก"*

### 2. Prompt สำหรับจำแนกหมวดหมู่ข่าว (Rule-Based Topic Classification)
> *"เขียนฟังก์ชันภาษา Python เพื่อจัดหมวดหมู่ข้อความเตือนภัยภาษาไทย (Topic Identification) โดยใช้ Keyword Matching แบ่งออกเป็น 4 หมวดหมู่หลัก ได้แก่ อุบัติเหตุทางถนน, เพลิงไหม้, ภัยธรรมชาติ/น้ำท่วม และภัยสารเคมี"*

### 3. Prompt สำหรับสร้าง Web Interface ด้วย Streamlit และ Custom CSS
> *"ช่วยสร้างหน้าจอ Web Application ด้วย Streamlit สำหรับระบบวิเคราะห์ข่าวอุบัติเหตุ โดยรับ Input เป็นข้อความหรืออัปโหลดไฟล์ CSV และแสดงผลลัพธ์เป็น Cards 4 ช่อง พร้อมปรับแต่ง Theme CSS ให้ภาพรวมเป็นโทนสีฟ้าเทอร์ควอยซ์ (Turquoise Blue) สลับขาวไข่มุก (Pearl White) และตัวอักษรสีเข้มอ่านง่าย"*
