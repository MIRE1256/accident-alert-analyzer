# ระบบวิเคราะห์โพสต์เตือนภัย/ข่าวอุบัติเหตุ (Accident & Emergency Incident Extraction System)

เว็บแอปพลิเคชันสำหรับประมวลผลข้อความภาษาไทยเพื่อสกัดข้อมูลสำคัญจากโพสต์แจ้งเตือนภัยหรือข่าวอุบัติเหตุ

## 📌 เทคนิค NLP ที่นำมาประยุกต์ใช้
1. **Regex & Cleansing:** ทำความสะอาดข้อความ ลบ URL, อีเมล, เบอร์โทรศัพท์ และสัญลักษณ์พิเศษ
2. **Tokenization & Normalization:** ตัดคำภาษาไทยด้วย PyThaiNLP และลบ Stopwords
3. **Topic Identification:** จำแนกประเภทของเหตุการณ์ (อุบัติเหตุจราจร, ภัยธรรมชาติ, เพลิงไหม้, สารเคมีรั่วไหล)
4. **POS & NER:** สกัดเอนทิตีสำคัญ ได้แก่ สถานที่เกิดเหตุ, วันเวลา, ผู้บาดเจ็บ/เสียชีวิต, และหน่วยงานช่วยเหลือ

## 🚀 วิธีการรันบนเครื่อง Local
1. ติดตั้ง Dependencies: `pip install -r requirements.txt`
2. รันแอปพลิเคชัน: `streamlit run app.py`
